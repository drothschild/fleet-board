Before scoring a mutant whose mapped test stayed green, check that the test reaches the mutated line by reading the test and the code path; when that is unclear (mocks, shell or jq pipelines, generated code), put a marker such as `echo reached >&2` on that line, run the same test, look for the marker in its output, and restore the line before making any scored mutant: the marker is a probe and is never part of a scored mutant.
